# 🔁 Estruturas de Repetição (For e While) em Python

Dois exemplos práticos comparando como utilizar os principais laços de repetição em Python: `for` e `while`.

## 📂 Arquivos
- **`repeticao_for.py`**: Utiliza a função `range(1, 31)` para iterar e exibir os números de 1 a 30.
- **`repeticao_while.py`**: Utiliza uma variável de controle e laço condicional para alcançar o mesmo resultado.

## 📌 Conceitos Praticados
- Laço `for` com `range(início, fim)`.
- Laço `while` com condição e incremento (`+= 1`).

## 🚀 Como Executar

Para testar o laço `for`:
```bash
python repeticao_for.py
```

Para testar o laço `while`:
```bash
python repeticao_while.py
```
